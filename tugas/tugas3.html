Pertanyaan Umum (FAQ)

1. Apa itu jQuery?
jQuery adalah pustaka JavaScript yang cepat, kecil, dan kaya fitur yang membuat hal-hal seperti manipulasi dokumen HTML, penanganan event, animasi, dan Ajax jauh lebih sederhana.
2. Mengapa menggunakan jQuery?
jQuery menyederhanakan kode JavaScript yang kompleks, meningkatkan kompatibilitas lintas browser, dan memiliki banyak plugin yang tersedia.
3. Bagaimana cara menyeleksi elemen di jQuery?
jQuery menggunakan sintaks seperti CSS, misalnya: `$("#id-elemen")` untuk ID, `$(".class-elemen")` untuk kelas, atau `$("tag")` untuk tag HTML.
4. Apa itu HTML DOM?
HTML DOM (Document Object Model) adalah antarmuka pemrograman untuk dokumen HTML. Ini mendefinisikan struktur logis dokumen dan cara mengakses dan memanipulasi dokumen tersebut.
5. Apa bedanya `toggle()` dengan `slideToggle()`?
Keduanya menyembunyikan/menampilkan elemen. `toggle()` langsung mengubah properti `display`, sedangkan `slideToggle()` menyertakan efek animasi sliding.
